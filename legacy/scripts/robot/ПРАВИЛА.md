# Правила нарезки шортсов (читается Claude перед каждой работой)
Правь этот файл сам — Claude будет следовать новой версии.

## Что беру из таблицы
- «Кто монтирует» = Артем, «Монтаж» = ТЗ поставлено, «Статус» ≠ Запощено.
- «Оформа» — не моя зона (СММ).

## Исходник
- Только 1080p. Папка = «Ролик», проект = <Ролик>.prproj, секвенция = «Тема».

## Монтаж
- Резать по словам из скобок ТЗ, в тихий момент между словами.
- Каждый план — отдельный клип, граница ровно на первом кадре нового плана.
- Илья почти всегда на фулскрин, кадр жёстко по нему, без дёрганья (одна позиция на план).
- Б-роллы: всё важное в кадре, при необходимости уменьшить масштаб. Фон на V1 (fon_full) уже лежит.
- Б-ролл с человеком (не Илья) — кадр по нему, как по Илье (пример: женщина, Position X = 1199 px).
- Документы, чертежи, планы, широкая графика — scale 56.25 (целиком влезает); фон fon_full под ними.

## Титры
- Одна строка, до ~22 знаков (в стиле «Сабы рилс» длиннее переносится), тайминг строго по речи.
- Никаких висящих предлогов/частиц в конце строки («на», «в», «и», «что», «это»…) — переносить вниз.
- Титр не начинается с тире (эффект диалога): склеить с предыдущим или заменить на запятую.
- Правлю только ошибки распознавания, грамматику, пунктуацию, ё; оговорки не переписываю по смыслу.
- Стиль «Сабы рилс» — применяю сам.

## Звук и конечка
- Хвосты кусков с запасом (до начала следующего слова), начала не удлинять.
- Мат закрываю звуком затвора на A2, в титрах звёздочки.
- Конечка сразу после речи, видео под ней ещё 0.6–1.6 с. Fade.png на V4.
- Обложку (maxresdefault.jpg) ставить в окошко конечки (в проект она тоже попадает).

## Титры: доп. правила корректора (взяты из srt-korrektor, 29.09.2026)
- Цифры, годы, даты и имена людей не трогать: «24 года» не превращать в «2024», имена не «улучшать».
- Тире между словами — «—» с пробелами. Между числами — короткое «–» без пробелов (15–20).
- Дробные числа через запятую (80,84). Числа от 5 знаков — с пробелом (100 000), четырёхзначные слитно (5000).
- Обращение «вы» — со строчной, кроме начала предложения.
- Запятая перед косвенным вопросом («понять, как это работает»), точка в конце законченной фразы — но в титрах точку в конце строки, которая продолжается в следующий титр, не ставить.
- Ё оставлять там, где она меняет слово: всё/все, сёла/села, узнаём/узнаем, совершённый/совершенный, нёбо/небо, осёл/осел.
- Слова, которых нет в речи, не добавлять («Корея» не превращать в «Южная Корея»), сокращения и разговорные названия не раскрывать.
- Написание: «в Украине», «Беларусь», «Кыргызстан», «Башкортостан», «Алматы», «кафе».
- Титры правлю по каждому титру отдельно: два титра не склеиваю, тайминг не трогаю.

## Что Артём правил руками в проекте «Мобилизация (ТЗ 2)» (29.09.2026) — теперь делаю сам
- Начало куска = слово из расшифровки + 0,06 с. Если рядом склейка плана — начинаю через 2 кадра после неё, короткий кусочек прошлого плана перед склейкой не оставляю (он удалял такие планы по 5–7 кадров в начале куска).
- Конец куска = конец слова + 0,06…0,16 с (хвост чуть длиннее слова, но без начала следующего).
- Конечка стартует за 3 кадра до конца речи (было 5).
- Кадрирование по лицу, масштаб 177,78 для Ильи и для плана с человеком — принято без правок. Вставка-карточка с вшитым текстом («Помогите найти отца») — масштаб 100 по центру, принято.
- Титры (текст) правок не потребовали.
- На стыке кусков расшифровка склеенного звука иногда «выдумывает» слово («Вступив», «Наступен») — это остаток чужого слова или щелчок склейки. Если такое слово есть — сдвигаю начало куска на слово и убираю его из титров.
- Если в колонке «Тема» пусто — секвенция «<Ролик> (ТЗ N)».

## Быстрый запуск (auto.py)
- `python3 auto.py spec.json stage1` — точки реза, склейки, лица, склеенный звук, расшифровка; лист кадров `work\<tag>_sheet.jpg`.
- Проверить лист кадров и первые/последние слова кусков, затем `python3 auto.py spec.json stage2` — титры и проект. Формат spec — в начале auto.py.
- Много кусков звука собираются на A1 отдельными клипами (`audios` в job.json).
