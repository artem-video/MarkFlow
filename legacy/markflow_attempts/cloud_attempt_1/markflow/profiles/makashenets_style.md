# Style Profile — Макашенец
# Источники: ГАЙД ПО МОНТАЖУ 2026.pdf + методички Ландыши/Дудь-Морген

## Главная установка
**Политика подаётся как видеоигра.** Это сквозная идея всего канала.
Информационные плашки, звуки из игр, HP-бары, ачивки, HUD — всё должно
читаться как один игровой интерфейс. Один шрифт, одна рамка, один акцент.

---

## ЗАПРЕЩЕНО

| Что | Почему |
|---|---|
| Отбивка Robert B. Weide | «Жутко заезжена» — прямая цитата |
| «Дверь мне запили» / «Пацаны вообще ребята» | Старые мемы. Можно только если по смыслу рифмуется с репликой |
| GOOOOOD NO из «Офиса» | Заезженный кадр из комедии |
| Эйс Вентура с ершиком | То же |
| Электронная / синтезированная музыка | Предпочитает бас, барабаны, акустику — «это придаёт киношности» |
| Один приём больше 3 раз за ролик | Четвёртый раз — уже тик, не приём |
| Шутки там, где реально страшно (интервью с пострадавшими, реальные смерти) | Ноль гэгов, ноль звучков |
| Выдуманные цифры, цитаты, должности | Пометить «проверить» и не подставлять правдоподобную ерунду |

## ОДОБРЕНО

### Звуки (TikTok-актуальные)
- **Vine Boom** — тяжёлый комичный удар
- **Taco Bell** — уведомление/bing
- **Chill Guy** — расслабленная пауза
- **Cartoon Transition** — вжух, переход
- **Spider Man** — поинтинг
- **FNAF 2** — ужас/внезапность
- **Звук рваной бумаги** — под запикивание мата
- Пак myinstants.com + собственные паки проекта

### Речевые приёмы
- **Замедление речи** — для подчёркивания тупости/шаблонности фразы (TikTok slowed)
- **Замедление + reverb** (slowed+reverb) для sigma/aura edits

### Визуальные приёмы
- **Длинные синхроны** — обивать мемами с шокированными животными в хромакее
- **Демотиваторы** — для особо противоречивых высказываний
- **LOW QUALITY / EmotiGuy** — бумерские жёлтые смайлы, нарочито всратый монтаж
- **Жопа из Губки Боба** — для «впечатляющих» цифр (падающий рейтинг, просмотры)
- **Гросс апы** — отвратительный крупный план, как в мультиках
- **Sigma/aura edit** со slowed+reverb — когда герой «думает, что крутой»; череп заменять на петуха
- **Цитаты нетипично** — не вырезка из статьи, а что-то оригинальное в оформлении

### Путин
- Называть: **Пыпа** или **ЛадимВладимыч**
- Когда говорит очевидную чушь → **эффект Spherize** (надуть лицо/голову)

### Игровая эстетика (главная)
- Всплывающие плашки подзвучивать игровыми звуками (шутеры, RPG)
- Ачивки, HP-бары, инвентарь, квесты, статы — для описания персонажей и событий
- Пример: «Захват Бахмута» → звук подобранной монеты в стратегии
- Пример: «Депутат несёт чушь» → плашка с нулевыми статами

### Музыка
- Бас-гитара, живые барабаны, акустика = кинематографичность
- НЕТ: электронике, синтезаторам, «продакшн-бите»

## Тональность
Сатирическая политическая аналитика. Не стендап — анализ через иронию.
Автор умный, устал от клише, хочет выглядеть свежо на фоне других обзорников.
Зритель должен чувствовать, что смотрит что-то умное — и при этом ржать.

---

## Красные зоны (без исключений)
- Реальные пострадавшие (вдовы, инвалиды, жертвы) — ноль гэгов
- Факты без проверки — лучше написать «сверить» чем поставить ерунду
- Приём использованный 3 раза — на четвёртый остановиться
