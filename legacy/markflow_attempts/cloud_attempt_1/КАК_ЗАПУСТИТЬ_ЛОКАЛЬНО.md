# Запуск MarkFlow на своей машине

## Что это даёт

Пайплайн автоматически строит черновой монтаж в Premiere Pro:
- **75 клипов** стендапа нарезаны по таймкодам из видео
- **70 маркеров** для ЛАЙВ вставок (YouTube, Кремль и т.д.)
- Итоговый `.prproj` открывается в Premiere без лишних действий

## Шаг 1: Установи зависимости

```bash
pip install faster-whisper
```

## Шаг 2: Извлеки аудио из видео

```bash
# Только аудио — ~300 МБ вместо 41 ГБ
ffmpeg -i "Копия Keyed-Video_2608311425_0001.mov" \
  -vn -acodec pcm_s16le -ar 16000 -ac 1 \
  audio_standup.wav
```

## Шаг 3: Транскрибируй (ASR)

```bash
# Скачает модель ~3 ГБ при первом запуске, дальше кэшируется
# На CPU: ~75 мин видео → ~40 мин транскрипция
python3 markflow/tools/run_asr.py audio_standup.wav -o words.json
```

## Шаг 4: Запусти полный пайплайн

```bash
python3 -m markflow.pipeline.run_pipeline \
  --gdoc_json    gdoc_raw.json \
  --words_json   words.json \
  --video_path   "C:/Users/Artem/Videos/Макашенец/МОДНАЯ ПРОПАГАНДА/Копия Keyed-Video_2608311425_0001.mov" \
  --out_dir      output_final \
  --project_name "Модная пропаганда ч2" \
  --fps 60.0
```

Пайплайн должен вывести `ИТОГ: OK` и создать `.prproj` в папке `output_final/`.

## Как получить gdoc_raw.json

```python
# gdoc_to_json.py — запусти один раз чтобы сохранить сценарий локально
import json

# Вставь сюда текст из Google Doc (Часть 2)
script_text = """...текст сценария..."""

with open("gdoc_raw.json", "w", encoding="utf-8") as f:
    json.dump({"fileContent": script_text}, f, ensure_ascii=False)
```

## Проблемы?

- **ИТОГ: ОШИБОК N** — читай вывод, скорее всего кривой путь к видео
- **matched 50/77** — нормально, алгоритм не находит очень короткие реплики типа "Стоп"
- **Очень медленно** — добавь `--model medium` в run_asr.py (быстрее, чуть хуже качество)
