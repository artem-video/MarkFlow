# MarkFlow — маршрутная карта для Артёма

Два места работы:
- **☁ Облако** — Claude Code в браузере (claude.ai/code), репозиторий `artem-video/MarkFlow`. Пишет код и тесты.
- **💻 ПК** — Claude Code **локально на ноутбуке** (в приложении Claude вкладка Code → локальная папка `C:\Users\Artem\Videos\MarkFlow\repo`; или в PowerShell команда `claude` в этой папке). Работает прямо в Windows: видит видеокарту, Python, диск G: и Premiere. Замеры, прогоны, приёмка.
- **Cowork сюда не подходит**: его терминал живёт в отдельной Linux-машине без видеокарты и без диска G:.

Правило одно: делаешь шаги по порядку, **каждый шаг — новая сессия**. В конце каждой сессии Claude сам
пишет, куда идти дальше и что вставить. Если он этого не написал — попроси: «напиши, что мне делать дальше».
Код руками не трогаешь никогда.

## Как писать замечания после приёмки

Прямо в ПК-сессию, как Егор писал правки: «03:12 лишний кат», «07:40 не тот дубль», «лайв Дудя встал раньше на 2 с».
Claude разберёт их, сравнит с планом и **сначала спросит**, прежде чем менять правила.

## Если что-то сломалось

- Облако пишет «готово», а отчёта с ПК нет — это не готово. Напиши: «где отчёт Gate 2 и Gate 3?»
- Premiere открыл пустой таймлайн — Gate 3 должен был это поймать. Напиши в ПК-сессию: «Gate 3 пропустил пустой таймлайн, разбери».
- Лимиты кончаются — облачные сессии короче, чем ПК-сессии; тяжёлое (прогоны) всегда на ПК.
