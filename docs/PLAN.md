# MarkFlow — план разработки

Документ для Claude Code (облако) и Cowork (ПК). Правила работы — в `CLAUDE.md`, пошаговая
инструкция для Артёма — в `docs/ROUTE.md`. Статус модулей обновляется в конце каждой сессии (таблица внизу).

---

## 1. Цель и эталон

**Цель первой версии (MVP):** Артём вставляет ссылку на сценарий, ссылку на исходники и папку проекта,
жмёт «Собрать» — через 10–20 минут в Premiere открывается `…_MF1_draft.prproj`: нарезанная говорящая
голова, лайвы на местах, комменты сценария маркерами, пресет голоса на дорожке. Проект редактируемый,
без перекодировок и субклипов.

**Эталонный выпуск:** Макашенец «МОДНАЯ ПРОПАГАНДА».
- Исходники: `Videos\Макашенец\МОДНАЯ ПРОПАГАНДА\` (B0001–B0004 от 28.08, добор 20260915_B0001, VO_MAKASHENETS_20260904.wav)
  и Google Диск (`Keyed-Video_2608311425_0001.mov`, 44.7 ГБ, 28:51, ProRes 422 LT 1080p60).
- Сценарий: гугл-док «МОЙ ЮТУБ_МОДНАЯ ПРОПАГАНДА» с комментариями (читать через API, не через html).
- Готовый монтаж Артёма (`МОДНАЯ ПРОПАГАНДА.prproj`, 17 секвенций) — **не эталон нарезки** (сценарий менялся
  после записи), но источник знаний: какие лайвы, музыка, звуки, дорожки и приёмы он использует.

**Мерило качества — сценарий** (итоговая версия дока, сценарий важнее расшифровки):

| Метрика | Порог MVP |
|---|---|
| Строки сценария, найденные в черновике ровно один раз | 100 % (иначе маркер `ПРОВЕРИТЬ` на месте пропуска/повтора) |
| Выбран последний дубль там, где фраза перезаписана | ≥ 95 % |
| Лишнее (команды, оговорки, вздохи, мусор между дублями) | ≤ 5 % длительности |
| Резы по живому слову (громкость на склейке выше порога тишины) | 0 |
| Импровизация вне сценария | не удалена, помечена цветом (осмысленная/смешная) |
| Лайвы: встали на своё место по сценарию | 100 % найденных; не скачанные — текстовым слоем |
| Проект открывается в Premiere, таймлайн не пустой и совпадает с планом | обязательно (Gate 3) |

## 2. Как работает программа (для любого канала)

```
[Окно] ссылка на док + (часть 1/часть 2 → поле первых/последних слов) + ссылка на исходники + папка проекта
   │
   ├─ ingest        исходники с Диска (замер: поток vs целиком) → локальный кэш; звук 16 кГц моно
   ├─ script        док + комменты → модель сценария (строки, типы, ссылки, выделения под комментами)
   ├─ asr           пословная расшифровка (модель — по замеру этапа 0) + огибающая громкости
   ├─ triage        «карта исходников»: основная съёмка / перезапись / добор / закадр / команды
   ├─ align+cut     сверка сценарий↔расшифровка, последний дубль, паузы, команды, импровизация
   ├─ lives         ссылки → скачать 1 раз → уточнить точку по слову и громкости ±5 с → поток или перекрытие
   ├─ comments      комменты сценария → маркеры (или дорожка субтитров — тест)
   ├─ voice         замер голоса → адаптированный пресет из пресетов Артёма на дорожку
   ├─ plan          всё выше → edit_plan.json
   ├─ write         шаблон/текущий проект + edit_plan → новый .prproj (_MF1_draft)
   └─ validate      Gate 2 проверки → отчёт
[Мост] сохранить/закрыть проект в Premiere → записать → открыть обратно
```

**Круги после черновика** (каждый — отдельная кнопка, по команде Артёма, новым файлом):

1. `MF1_draft` — черновик (MVP)
2. `MF2_jokes` — шутки с индексом уверенности (Gemini; запасной путь — задание для Cowork)
3. `MF3_sfx` — звуки по паттернам (pop-транзишн → звук, жёлтая плашка scale → маркер, typewriter → клавиатура …)
4. `MF4_music` — музыка по настроению (после шуток и звуков)
5. `MF5_sizes` — раскладка по крупностям (развитие `alternate_any.py`, + анимация масштаба ключами → V3)
6. `MF6_qa` — проверка перед сдачей: орфография в графике, пропуски/расхождения со сценарием, повторы, микропланы, чёрные кадры

«Где» = где идёт сессия: ☁ облако (Claude Code), 💻 ПК (Cowork).

## 5. Решения, принятые с Артёмом (30.09.2026)

1. Начинаем с общей базы, обучаемся на Макашенце «МОДНАЯ ПРОПАГАНДА». Егор — друг, его материалы — примеры.
2. Проект собирается записью `.prproj` от проекта, сохранённого Premiere; XML — только запасной путь.
3. Окно Windows (Electron) + CEP-мост, как в автотитрах. CEP — пока работает; отвалится — думаем.
4. Лучшее из старых скриптов переносится и нормализуется под задачу; качество/битрейт — по исходнику.
5. Модель расшифровки — по замеру на разных исходниках, не по вере.
6. Облако пишет код, ПК — замеры и приёмка; «готово» только после трёх проверок.
7. Мерило — итоговый сценарий; импровизация и смешной мат — цветом (Артём собирает блуперсы).
8. Разбор исходников — сам, «как в поле», отчётом, без остановки.
9. Круги: черновик → шутки → звуки → музыка → крупности (последними, по команде) → проверка. Каждый круг — новым файлом.
10. Голос — в первом круге. Думающие этапы — Gemini (ключ `Videos\MarkFlow\gemini_api.txt`), запасной путь — Cowork.
11. Ассеты — ссылками на папки Артёма, программа индексирует сама.
